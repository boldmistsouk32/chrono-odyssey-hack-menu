**Chrono Odyssey Hack Menu** is a curated list of Chrono Odyssey open-source tools:

- **Quality-of-Life Helpers** — inventory catalog, route manager, overlay notes

## ✨ Features

### ESP
- State Viewer — read out combat and movement states on screen
- Tracker Panel — visualize nearby entities for study
- Route Notes — record and review travelling paths
- Playback Speed — adjust study playback for analysis (0.1x to 5x)

### Wallhack
- Gear Catalog — browse equipment, dyes, trails, effects
- Custom Loadout Notes — organize character cosmetics
- Marker Overlay — improved visibility of world markers

### Aimbot
- Practice Notes — segment study on any layout
- Camera Control — manually adjust the view mid-session
- Input Buffer Notes — chain complex maneuvers in the editor
